# The Worst Pizza Topping

One-liner entry for make.fun competition
`u-motasimfuad-the-worst-pizza-topping-062c6893` — pitch a terrible pizza
topping in a single line under 200 characters.

## The line

> Our signature pizza is topped with wet newspaper - it sticks to the roof of your mouth, but the headlines are free.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/out python3 main.py
```

Writes exactly the line above (no trailing newline) to
`<MAKEFUN_OUTPUT_DIR>/entry.txt`. If `MAKEFUN_OUTPUT_DIR` is unset, it
writes to `/output/entry.txt`. Python 3.13, standard library only.
